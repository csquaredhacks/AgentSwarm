Can't connect?

If won't open on a teammate's laptop: on the host, allow Node.js through the firewall (on Windows, run this in an admin PowerShell: New-NetFirewallRule -DisplayName AgentSwarm -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow). If the Wi-Fi blocks laptop-to-laptop traffic, run npx cloudflared tunnel --url http://localhost:3000 on the host and share the https://...trycloudflare.com/join link it prints instead.
